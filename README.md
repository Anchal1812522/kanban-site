Kanban Site 📝

A simple and interactive Kanban Task Management Website built using HTML, CSS, and JavaScript. This project helps users manage their daily tasks by allowing them to create, organize, and delete tasks easily.

🚀 Features

Add Tasks: Create new tasks easily.

Delete Tasks: Remove tasks when they are completed or no longer needed.

Drag and Drop: Move tasks between different columns.

Task Management: Organize tasks using a Kanban board layout.

Local Storage: Save tasks in the browser so they remain available after refreshing the page.

Responsive Design: Simple and user-friendly interface.

🛠️ Technologies Used

HTML5 – Structure of the website.

CSS3 – Styling and layout.

JavaScript – Functionality and DOM manipulation.

Local Storage – Store tasks in the browser.

Drag and Drop API – Move tasks between columns.

🎯 Project Objective

The main objective of this project is to practice JavaScript DOM manipulation, event handling, drag-and-drop functionality, and Local Storage while building a practical task management application.
